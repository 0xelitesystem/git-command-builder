Git Command Builder

From "I want to..." to the exact command

You know what you want to do. You just do not remember the incantation. Search for the goal in plain words, pick the task, and get the exact command with every flag explained. Destructive commands carry a visible warning and a safer alternative.

Pick a task on the left, or search above. Placeholders like <branch-name> turn into your real values as you type them into the small input fields.

Honest scope note: this covers the everyday tasks that send most people searching the web, not the full git reference. For anything exotic, git help <command> is the source of truth.

Everything runs locally in your browser. No external dependencies, works offline. Nothing you type is sent anywhere.
